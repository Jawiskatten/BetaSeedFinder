# Installation

## Source checkout

1. Clone or extract the repository to a normal writable folder.
2. Install JDK 17 or newer.
3. Build or download the worker for your GPU backend.
4. Run `RUN_GPU_GUI_AUTO.bat`, or force a backend with the AMD/NVIDIA launcher.

Do not run the application from inside a ZIP.

## AMD

Install AMD HIP SDK for Windows, then run:

```text
BUILD_AMD_BACKEND.bat
TEST_AMD_BACKEND.bat
RUN_GPU_GUI_AMD.bat
```

## NVIDIA

Either build locally with CUDA Toolkit and Visual Studio C++ Build Tools, or download the artifact generated by the repository's NVIDIA workflow. Then run:

```text
TEST_NVIDIA_BACKEND.bat
RUN_GPU_GUI_NVIDIA.bat
```

## Output

On first launch, select an output directory. Search runs can grow large; keep several gigabytes free. Local output and configuration are ignored by Git.
