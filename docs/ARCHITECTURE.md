# Architecture

BetaSeedFinder has one user-facing Windows launcher and two internal native workers.

1. `BetaSeedFinder.exe` starts the bundled Java Swing application.
2. The Java application detects the installed GPU vendor.
3. Radeon systems use `backend/amd/BetaSeedFinderWorker.exe`.
4. GeForce/Quadro systems use `backend/nvidia/BetaSeedFinderWorker.exe`.

Both workers are built from the same shared source under `native/src`. The AMD worker uses HIP; the NVIDIA worker uses CUDA. The release is universal because both are present in the same package.

The Java application owns settings, run history, exact Java terrain verification, result storage, and the UI. The selected worker performs the high-throughput early GPU pipeline.

The bundled Java runtime is generated by `jpackage`. Users launch only `BetaSeedFinder.exe`; the backend directories are implementation details.
