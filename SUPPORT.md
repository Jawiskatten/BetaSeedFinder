# Support

## Before opening an issue

1. Read `docs/INSTALLATION.md` and `docs/TROUBLESHOOTING.md`.
2. Run `GpuBackendDoctor` or the matching backend test script.
3. Include the application version, Windows version, GPU model, driver version, Java version, and backend selection.
4. Attach only the smallest relevant log. Remove personal paths or unrelated seed results.

## Security reports

Do not post suspected security vulnerabilities publicly. Follow `SECURITY.md`.

## Scope

Support is best-effort for the public alpha. Performance tuning for untested GPUs and recovery of damaged local result folders may require reproducible logs.
