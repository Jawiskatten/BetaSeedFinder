# Optional assets

The public source tree intentionally contains no bundled Minecraft textures, third-party fonts, or unlicensed sound files.

BetaSeedFinder works without them:

- the interface falls back to Consolas when no optional font is present;
- texture panels render their built-in color/gradient fallback;
- missing hit sounds are ignored.

Before adding any asset to a public repository or release, confirm that redistribution is permitted and include the required license notice.
